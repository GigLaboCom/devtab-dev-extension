Tool page and Table

What every tool page has in common (@workspace/ui tool-page, style-gpui.css kit-tool-*): the head with the title, the summary and the host's history line; a row of options and actions; input and result panes; a message under a pane (an error, a note, a success). Then the parts the tools share: a copy button (words, or an icon that turns into a check), result rows (kit-result-row*), the file drop zone (kit-file-drop*, shown with a file over it), the frame of someone else's document (kit-framed-document: a srcdoc frame sandboxed without scripts, as Markdown Preview and HTML Preview show their previews) and the table (cn-table*).
